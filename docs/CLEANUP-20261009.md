- Remove the Codex Companion service, app-server helper, session watcher, quota models, pet renderers, menus, preview assets, firmware protocol, Windows protocol library, and companion-only tests/documentation.
- Retain weather, music, stocks, Pomodoro, salary, device management, USB/Wi-Fi, OTA, battery, IMU rotation, and host sleep awareness.

## Validation

- macOS: 52 XCTest cases pass (including retained runtime, mode-catalog coverage, and removed network-preference migration).
- Firmware: NodeMCU hybrid, FuBoTV USB-only, and Waveshare ESP32-S3 build targets pass.
- `git diff --check` passes.

## Existing limitations outside this cleanup

- Windows emits four localized stock-name strips while firmware supports five rows.
- Device `POST /reset-wifi` is not authenticated. Use only a trusted isolated LAN until a separately scoped administration-security change protects destructive routes.
- Windows currently has no USB serial or weather-data provider.
